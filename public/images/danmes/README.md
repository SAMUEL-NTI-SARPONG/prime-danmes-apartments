# Prime Danmes property photography

This folder contains the 17 unique property photographs supplied through the
Prime Danmes Airbnb listing photo tour:

https://www.airbnb.com/rooms/1343379466143336908

The images were downloaded on 2026-08-24 and renamed by room/view so their use
across the site remains clear and maintainable. They are stored locally as AVIF
assets to avoid depending on Airbnb's image CDN at runtime.
